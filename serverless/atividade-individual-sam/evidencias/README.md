# Evidencias da atividade individual serverless

Salve aqui capturas reais das execucoes. Nao inclua credenciais nem substitua os resultados observados por exemplos.

Capturas recomendadas:

1. `sam build` concluido e `sam --version`.
2. Duas invocacoes por evento, com os tempos visiveis.
3. Chamadas HTTP ao endpoint local e respostas do `curl`.
4. Campo `invocacaoNesteAmbiente` antes e depois de iniciar `--warm-containers LAZY`.
5. Erro observado com Timeout de 3 segundos.
6. Resposta apos aumentar o Timeout para 10 segundos e reconstruir.

Registre os tempos e os valores do contador no README usando os resultados da sua propria execucao.
